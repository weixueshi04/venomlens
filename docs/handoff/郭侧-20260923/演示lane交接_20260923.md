## 3. 明天演示操作

```bash
RECOGNITION_MODE=hhodata LIVE_CALL_LIMIT=<对账后设定> HHODATA_CLASS=R \
HHODATA_API_KEY=<env 注入> PROXY_TOKEN=<≥16字符,另生成> DEMO_RELEASE_UNVERIFIED=1 \
python -B -m uvicorn inference.app:app --host 127.0.0.1 --port 8765
```
